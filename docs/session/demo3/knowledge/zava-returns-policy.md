# Zava returns policy

_Fictional demo content. Version 3.2, effective 1 September 2026._

## Standard returns

- Customers can return most items within **30 days** of delivery for a full refund to the original payment method.
- Items must be unused, in their original packaging, and accompanied by the order number.
- Refunds are issued within **5 business days** after the warehouse receives the item.

## Exceptions

| Category | Return window | Notes |
| --- | --- | --- |
| Electronics | 14 days | Must include all accessories; opened software is not returnable |
| Outdoor furniture | 60 days | Free pickup for orders above €500 |
| Clearance items | Not returnable | Marked "final sale" at checkout |
| Gift cards | Not returnable | — |

## Damaged or wrong items

Report damaged or incorrect items within **48 hours** of delivery through the order page. Zava pays return shipping
and sends a replacement at no cost; no proof of purchase beyond the order number is needed.

## Zava Plus members

Zava Plus members get an extended **45-day** return window on all returnable categories **except electronics**, which
keep the 14-day window, and free return shipping on every return.
